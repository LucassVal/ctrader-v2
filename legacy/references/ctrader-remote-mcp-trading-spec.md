# cTrader Remote MCP — Trading Operations Spec

> **Source**: https://help.ctrader.com/ctrader-ai-agent-connect/remote-mcp/trading/
> **Underlying API**: cTrader Open API v2 (ProtoBuf over WebSocket)
> **Proto source**: https://github.com/spotware/openapi-proto-messages
> **Last updated**: 2026-06-17 (docs), proto files from master

---

## Architecture

The cTrader Remote MCP server is an **AI-agent-native layer** over the cTrader Open API v2.  
The MCP server exposes trading operations as **MCP tools** that accept natural-language prompts.  
The underlying protocol is **Protocol Buffers (proto2)** over a persistent WebSocket connection.

**Key insight**: The MCP help docs only show natural-language prompt examples.  
The actual method names, parameter schemas, and return schemas are defined in the ProtoBuf `.proto` files.

---

## 1. TRADING OPERATIONS (Request → ExecutionEvent)

All trading requests return a **ProtoOAExecutionEvent** (payloadType=2126).  
The event contains the resulting `position`, `order`, `deal`, and optional `errorCode`.

### 1.1 ProtoOANewOrderReq — Place Order
- **PayloadType**: 2106 (`PROTO_OA_NEW_ORDER_REQ`)
- **Requires**: `accessToken` with "trade" permission

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `ctidTraderAccountId` | int64 | **required** | Trader's account ID |
| `symbolId` | int64 | **required** | Symbol ID in cTrader |
| `orderType` | ProtoOAOrderType | **required** | MARKET(1), LIMIT(2), STOP(3), MARKET_RANGE(5), STOP_LIMIT(6) |
| `tradeSide` | ProtoOATradeSide | **required** | BUY(1), SELL(2) |
| `volume` | int64 | **required** | Volume in **cents** (0.01 units). e.g. 100000 = 1000.00 units = 10 lots |
| `limitPrice` | double | optional | Limit price (LIMIT orders only) |
| `stopPrice` | double | optional | Stop price (STOP, STOP_LIMIT orders only) |
| `timeInForce` | ProtoOATimeInForce | optional | GTC(2, default), GTD(1), IOC(3), FOK(4), MOO(5) |
| `expirationTimestamp` | int64 | optional | Unix ms, for GTD orders |
| `stopLoss` | double | optional | **Absolute** SL price (e.g. 1.11500). NOT for MARKET orders |
| `takeProfit` | double | optional | **Absolute** TP price (e.g. 1.13000). NOT for MARKET orders |
| `comment` | string | optional | Max 512 chars |
| `label` | string | optional | Max 100 chars |
| `baseSlippagePrice` | double | optional | For MARKET_RANGE |
| `slippageInPoints` | int32 | optional | For MARKET_RANGE and STOP_LIMIT |
| `positionId` | int64 | optional | Reference to existing position to modify |
| `clientOrderId` | string | optional | User-specific ID, max 50 chars |
| `relativeStopLoss` | int64 | optional | In 1/100000 units. BUY: SL = entry - relative; SELL: SL = entry + relative |
| `relativeTakeProfit` | int64 | optional | In 1/100000 units. BUY: TP = entry + relative; SELL: TP = entry - relative |
| `guaranteedStopLoss` | bool | optional | Required for Limited Risk accounts |
| `trailingStopLoss` | bool | optional | Enable trailing SL |
| `stopTriggerMethod` | ProtoOAOrderTriggerMethod | optional | TRADE(1, default), OPPOSITE(2), DOUBLE_TRADE(3), DOUBLE_OPPOSITE(4) |

**Order Types:**
| Enum | Value | Description |
|------|-------|-------------|
| MARKET | 1 | Execute immediately at best available price |
| LIMIT | 2 | Execute at specified price or better |
| STOP | 3 | Trigger when market reaches stop price, then execute as market |
| STOP_LOSS_TAKE_PROFIT | 4 | Protection order (generated by server) |
| MARKET_RANGE | 5 | Market order with slippage range |
| STOP_LIMIT | 6 | Stop order that becomes a limit order when triggered |

**Examples (from doc):**
```
Buy 1 lot of EURUSD at market.
Sell 0.5 lots of GBPUSD at market price.
Place a limit buy on EURUSD at 1.1200 for 1 lot.
Place a sell stop on EURUSD at 1.1100 for 1 lot.
Buy 1 lot of EURUSD at market with a stop loss at 1.1150 and take profit at 1.1300.
Place a limit buy on GBPUSD at 1.3200 for 0.5 lots with a 50-pip stop loss and 100-pip take profit.
Buy 1 lot of EURUSD at market. Label it 'swing-trade' and add the comment 'Breakout entry'.
```

### 1.5 ProtoOAClosePositionReq — Close Position (Full or Partial)
- **PayloadType**: 2111 (`PROTO_OA_CLOSE_POSITION_REQ`)

|-------|------|----------|-------------|

**Partial close**: set `volume` to less than the full position volume.

**Examples:**
```

```

## 5. VOLUME UNITS

Volume is expressed in **cents of a unit** (1/100 of base units):
- `100000` = 1,000.00 units = **10 standard lots**
- `10000` = 100.00 units = **1 standard lot**  
- `1000` = 10.00 units = **0.1 lots**
- `100` = 1.00 units = **0.01 lots**

Standard forex: 1 lot = 100,000 units → protocol value = 100,000 × 100 = **10,000,000**

---

## 6. PRICE FORMAT

- **Absolute prices** (stopLoss, takeProfit, limitPrice, stopPrice): `double`, e.g. `1.11500`
- **Spot prices** (bid, ask in ProtoOASpotEvent): `uint64` × 100,000, e.g. `111500` = 1.11500
- **Relative SL/TP**: `int64` × 100,000, e.g. `500000` = 5.0 pips
  - BUY: SL = entryPrice - relativeStopLoss/100000
  - BUY: TP = entryPrice + relativeTakeProfit/100000
  - SELL: SL = entryPrice + relativeStopLoss/100000
  - SELL: TP = entryPrice - relativeTakeProfit/100000

## 10. IMPORTANT NOTES

1. **The MCP server is prompt-driven**: AI agents send natural-language prompts, and the MCP server translates them to ProtoBuf requests. The exact JSON-RPC method names are MCP tool names internal to the server implementation, not publicly documented in the help pages.

2. **Confirmation mode**: Configure `request confirmation` for every trading operation in the client setup.

3. **Session requirement**: Requires an active cTrader Web session. Token is per trading account.

4. **SL/TP on MARKET orders**: Not supported — must use `ProtoOAAmendPositionSLTPReq` after fill.

5. **Volume granularity**: Always in cents. Check `ProtoOASymbol.stepVolume` for minimum increment.

6. **Money digits**: All monetary values (swap, commission, margin, balance, PnL) are multiplied by 10^`moneyDigits`. Check `ProtoOATrader.moneyDigits` and `ProtoOAPosition.moneyDigits`.

7. **Symbol distance limits**: `ProtoOASymbol.slDistance`, `tpDistance`, `gslDistance` define minimum distances from current market price.
